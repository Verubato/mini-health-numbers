# MiniHealthNumbers

In Classic and TBC the health value of mobs and players aren't available and only the percentage is shown on the target frame. It's in high demand for a solution to show the real health value on mobs/players as this is very useful information.

That's what this addon does; shows the real health values of mobs, and calculates/guestimates players health based on combat log events.

This is a very new addon and needs testing, so any feedback is more than welcome!
